Claude Architect Lab

Four documents, one exam-prep project

This project is a hands-on study exercise for the Claude Certified Architect (Foundations) exam, built around a fictitious licensing consulting firm's state-by-state money-transmitter-licensing work. Below are the five pages that make it up, each covering a different angle — read them in this order, or jump straight to whichever one you need.
