Review #47 — a voice for each skin, and a voice menu, in jarvis-test.html

The user asked for the skins to sound more different before promoting the test copy. Each skin now has a ranked list of voices that suit it: Daniel, Ryan or a Google UK male voice for Jarvis; Ralph, Guy or Davis for Morpheus; Andrew, Brian or Junior for Stanley. The page uses the first one the device has. A voice menu beside the skin button lists every English voice on the device. Picking one switches straight away, plays a short line in that voice, and is remembered for that skin.

01Security

Voice names and the saved picks are handled as text
Confirmed clean

The menu is built with new Option(text, value), so a voice name is only ever text, never markup. A grep still finds 0 innerHTML or eval(. The saved picks (localStorage['jarvis-voices']) are read only for the three skin ids, and only as strings of up to 200 characters. A saved name is used only if a voice of exactly that name exists on the device. The suite loads a store holding a constructor key and a number, and the page opens with no errors. The CSP meta tag is unchanged, and nothing new is fetched: the voices are the device's own.

02Code quality & accessibility

The menu fits beside the skin button on a phone
Fixed

In headless Chromium at 390 px wide, with fake voices added so the menu shows, the first layout put the menu on a row of its own and squeezed the clock onto two lines. The menu is now capped at 40% of the screen width, with the clock kept to one line, so the menu sits beside the button. The page doesn't scroll sideways (scrollWidth 390). The menu is a native <select> labelled "Voice", with the page's amber focus outline and the skin's own colours, so it gets the device's own picker and works with a keyboard and screen readers.

Chosen voices get a gentler pitch
Confirmed clean

With only a generic voice, Morpheus drops to pitch 0.55 and Stanley rises to 1.2, because pitch and speed have to carry the character. A voice picked for the part (from the skin's list, or chosen in the menu) already sounds right, so it gets milder values: Morpheus 0.82, Stanley 1.08, Jarvis 0.95. Otherwise Ralph, already deep, would sound unnaturally low.

Suite extended for the voice menu
Confirmed clean

20 new checks in a "Voices" section, against a fake device with iPhone-style voices (Samantha, Daniel, Ralph, Junior, Karen, and a French voice). They check that the menu lists the five English voices plus Auto and leaves out the French one, that each skin gets its preferred voice, and that a pick plays a sample, is saved for that skin only, survives a reload, and is cleared by choosing Auto. One failure on the first run was a wrong expected count in the test (five English voices plus Auto makes six). The count was worked out again from the voice list before it was changed.

The voices themselves not heard
Open

Headless Chromium has no voices, so the voice names in each skin's list are what Apple, Microsoft and Google publish, not ones heard here. If a device has none of them, the skin falls back to its accent and the old pitch and speed, so it still works. The proof is the user trying it. Some iPhone voices, Ralph and Junior among them, may need downloading under Settings → Accessibility → Spoken Content → Voices before they appear in the menu.
