Review #21 — droid/plan.html & droid/build-plan.html Codespaces pivot

The user wants to avoid installing both Android Studio and Claude Code directly on the Windows laptop, using a GitHub Codespace (cloud Linux dev container) for everything instead. This is the third toolchain this pair of documents has described (Termux on a tablet → Android Studio on Windows → a GitHub Codespace). Both files' build-environment sections, hardware requirements, and command syntax (gradlew.bat → ./gradlew, since the container is Linux again) were updated, a new "bridge the phone to the Codespace" decision was added (two options, since a cloud container can't see a USB device), and the NFC "unavailable" negative test — previously assigned to an Android Studio emulator that no longer exists in this version — was moved to a mocked-NfcAdapter unit test.
