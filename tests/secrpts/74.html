01Security and privacy

On without any switch: what anyone can now do
Open

Review 72 kept the proxy off unless you turned it on, and noted that while it's on, a script that fakes the page's Origin can ask it questions (12 a minute per address). It's now on all the time, so that's true all the time, for anyone who finds the address, which is in this public repo. Each answer is short (at most 512 tokens out), so a question costs a fraction of a cent. The real limits are the budget alert and the daily request quota on the key's Google project (Session 17, step 3). Google can't be reached from this container, so whether those are set up is yours to confirm. Every visitor to the test copy is told when it's on, and what's sent, as before. This is your choice, recorded in the build plan, and it stays open until Edge Config or SUPERCHARGE=false takes over.

Still off where it should be
Confirmed clean

The default applies only when SUPERCHARGE is unset or blank. Any value other than true or on (any case) is off, so SUPERCHARGE=false turns it off with a redeploy. With no GEMINI_API_KEY it's off. A SUPERCHARGE_UNTIL that has passed, or can't be read, is off. Once Edge Config is connected, it decides, and a failed read is still off. Each of these is a check.
