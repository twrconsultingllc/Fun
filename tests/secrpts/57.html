01The fix

A failed mic tap did nothing at all
Fixed

Reported on 2026-10-10: "when I click the mic, nothing happens". In headless Chromium, with a fake recognizer that throws like Chrome's real one, the mic worked on both pages, at 1280×800 and 390×844, and after every feature added today (help links, a link click, dreaming, the memory core open and closed, a reboot, a scene opening on start-up). So the cause wasn't found here. What the check did find is that when Chrome's speech recognition fails, the page showed nothing: no LISTENING and no message. That happens when the mic is blocked for the site (Chrome blocks it by itself after its prompt is dismissed a few times), when there's no working microphone, or when the speech service can't be reached. micTrouble() now explains each of those in the chat, in both copies. A deliberate stop ("aborted") stays silent, and a start that fails for any reason but "already listening" says so too.
