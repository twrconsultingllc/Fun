Review #56 — J.A.R.V.I.S. Test: command links in the help answer

When you ask what Jarvis can do, or he doesn't understand you, the commands in his answer are now links in the chat bubble, in six Infinity Stone colours. You can still say a command, or click it to send it. Built in jarvis-test.html only.

01Security

Links are built as elements, never as HTML
Confirmed clean

An answer marks a command as ⟦label|command⟧. add() splits the text on that pattern and builds text nodes and <button> elements with textContent. The page still has no innerHTML (grep: 0). Your own messages are always plain text.

A link could have said one thing and done another
Fixed

Found while testing. The first version allowed any marker whose command was one of Jarvis's, so typing "remember that ⟦make a heart|reboot⟧ is fun" gave a link reading "make a heart" that rebooted him. Links are now allowed only for the exact label-and-command pairs in Jarvis's own help lists. Any other marker, typed or echoed, shows as plain words. Two checks pin this.

No new host or permission
Confirmed clean

The CSP is unchanged. A click calls the same handle() as typing, so it can do nothing that typing the command couldn't.

02Code quality & behaviour

Every link works
Confirmed clean

The suite runs each of the 35 link commands through answer() and none gets "I didn't understand". reboot is checked on its own, since it shows the boot screen. Clicking a link puts the command in the log as your message, and Jarvis answers it. jarvis-test suite: 751 passed (was 730). Ran node run.mjs --page=jarvis-test.html only.

Speech and the caption stay plain
Confirmed clean

say() speaks plainText(), so no marker is read aloud, and Chrome's 160-character pieces are measured on what is actually spoken. The projector caption gets plain text too.

Chromium: all three skins, both sizes
Confirmed clean

Headless Chromium at 1280×800 (Jarvis, Matrix) and 390×844 (Jarvis, Panthers) showed 35 links in 6 distinct colours, no sideways scroll, and no page errors or CSP violations. A mouse click on "flip a coin" and Enter on the first link (keyboard) both sent their commands. A comma after a link used to wrap onto a line of its own on the phone. It now stays with the link.

Contrast
Fixed

Computed against each skin's bubble background. The first colours dropped to 4.07:1 (blue on the Panthers bubble) under the hover tint. With a lighter blue, red and purple and a 10% hover tint, the lowest of all six colours, in three skins, with and without hover, is 5.16:1.

Only in the test copy
Open

By design: jarvis.html gets the links when you promote the test copy.
