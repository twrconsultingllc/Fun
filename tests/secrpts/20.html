Review #20 — droid/plan.html & droid/build-plan.html Windows pivot

The user decided to stop developing Sentinel via Termux on an Android tablet and switch to Android Studio on a Windows PC, with a single Samsung phone for on-device testing (no tablet at all). This touched both design documents: plan.html's "Build & test" decision, its data-model NFC assumption, its KSP justification, its whole build-environment section (renamed from Termux to Windows/Android Studio, with the Termux aapt2/same-device-install blockers removed since they don't apply on this platform), and its build-order/verification sections. build-plan.html's masthead, status/key callouts, session index table, and all seven sessions were updated for the new hardware story, with Session 1 rewritten from scratch around Android Studio setup, phone Developer Options, a native Windows Claude Code install, and a GitHub connection step — real shell commands were moved into new <pre><code> blocks per the just-added CLAUDE.md rule on copyable commands, instead of staying inline. A matching pre/pre code CSS rule was added to build-plan.html, copied from plan.html's existing one.
