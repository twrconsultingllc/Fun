The versions waited for a flag that never cleared
Fixed

The versions started once speakingNow() turned false. That reads speechSynthesis.speaking, which on Android Chrome can stay true after cancel() even when nothing is playing, so they never started. My first idea was a timing race with his thinking pause. It didn't reproduce, and the old page passed the new end-to-end check, so I didn't claim it. With speechSynthesis.speaking forced true in Chromium, as on the phone, the page you had failed the check, and the fixed page passed it. The fix is sayAfter: say() runs it once that answer has been said in full, in whatever voice. The versions now start from the intro's own end, and nothing asks the speech engine.

Reproduced: Chromium step 13 types "compare voices" twice, once normally and once with the speech flag stuck on. The live page (82934b1) failed the second run. The fixed page passed both, tagged VERSION A · CHARON, B and C, with four requests to Google (the intro, then A, B and C). The first draft of that check passed against the broken page, because it read the tags left from the earlier run. It now reads only lines after the command.
