Review #46 — skins, orb faces and learned phrases in jarvis-test.html

Three features on the test copy only, as CLAUDE.md asks for new J.A.R.V.I.S. work. Jarvis can switch to a Matrix skin, where he becomes Morpheus, or a Panthers skin, where he becomes Stanley C. Panther (the Florida Panthers' mascot, named after the Stanley Cup). Each skin has its own face in the orb's centre, drawn in code characters: an Iron Man style helmet, Morpheus, and Stanley. 01Security

Learned phrases can't inject markup or pollute objects
Confirmed clean

The phrase store is localStorage['jarvis-learned'], a JSON object of phrase to meaning. Anything typed or spoken comes back to the screen only through say() and add(), which use textContent. A grep finds 0 innerHTML or eval( in the page. The store is loaded into Object.create(null), keeping only string values, with phrases up to 120 characters and meanings up to 200. So a stored __proto__ key is a plain entry, not a prototype change. Phrases are normalised to [a-z0-9' ] before they're used as keys. The suite checks that a corrupt store and a non-string value are ignored, and that teaching __proto__ leaves Object.prototype alone. The store holds at most 200 phrases and drops the oldest first. "Forget what you learned" clears it.

The saved skin is checked before use
Confirmed clean

localStorage['jarvis-skin'] is used only if Object.hasOwn(SKINS, k), so a value like constructor falls back to Jarvis. The suite checks that case. The skin id ends up only in data-skin on the root element and as a lookup key.

No new network use, CSP unchanged
Confirmed clean

The Matrix rain and the three faces are drawn on canvases in the page's own script, with no images, fonts or libraries added. A diff of the CSP meta tag shows no change, and there are still 0 script[src]. Nothing new leaves the device: learned phrases stay in localStorage. Speech recognition is still the only online part, and the existing mic note already says so.

02Code quality & accessibility

Skin colours checked for contrast
Fixed

Computed WCAG ratios. Matrix: label #2ec95a is 9.49:1 on #000300 and 8.36:1 on #001a06, and text #d4ffdc is 16.64:1. Panthers: the first red, #ff4458, was only 4.44:1 on the navy #0a2552 in the middle of the page. The STANDBY label is shown at 80% opacity, which brought it down to 3.88:1. Fixed by changing the red to #ff7381 (5.73:1 on navy, 7.66:1 on #020814) and showing the state label at full opacity on that skin. The gold label #d4b47a is 7.58:1 on navy, and text #f1f4fa is 13.62:1.

Suite extended for skins and learned phrases
Confirmed clean

55 new checks in three sections ("Skins", "Learned phrases", "Remembered across visits"), using the existing fake speech engine. They cover: which phrases switch skins and which must not (for example "i want to go to jupiter jarvis", which the first pattern wrongly read as a skin switch until it was tightened), each persona's voice pitch and rate, the not-understood answer, "nothing" moving on, teaching and recalling a phrase, a learned phrase that switches skin, a meaning Jarvis doesn't understand either, and the store surviving a reload. jsdom has no canvas, so the faces are checked by the Chromium screenshots above, not by the suite.

Voices not heard, mouth movement not seen
Open

Headless Chromium has no speech voices. So Morpheus's lower, slower voice and Stanley's brighter one are checked only as the pitch and rate passed to each utterance. And because nothing ever speaks, the orb never enters SPEAKING, so the faces' moving mouths and flaring eyes weren't seen in the real page. They were seen on the preview page, which uses the same drawing code. Which voice a phone picks depends on what it has installed. The proof is the user trying it on the live test page.

Any reply after "What were you trying to say?" is learned
Open

On purpose, to keep it simple for voice: the reply doesn't need a "what I meant was" prefix. So if the user asks something unrelated instead, and Jarvis understands it, the earlier phrase gets linked to it. Jarvis always says what he learned ("Next time you say X, I'll know you mean Y"), and "forget what you learned" clears it. Left open until the user has tried it.
