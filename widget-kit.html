Widget Kit

Four custom elements, each with its own encapsulated Shadow DOM — styles defined inside one element never leak out, and outer page styles never leak in. No framework, no build step: customElements.define() and a shadow root are all this needs.

<neon-badge>

A presentational pill. tone and pulse are reflected attributes that drive the shadow-internal styling.

<rating-stars>

Click a star to set value and dispatch a rating-change event. Try the read-only one below — clicks on it do nothing.

<collapse-panel>

A disclosure widget. The header toggles the reflected open attribute and fires toggle; setting .open from script does the same thing.

Why Shadow DOM?

Each of these components renders into its own shadow root, so its internal <style> can use plain class names like .header without ever colliding with this page's own .header, if it had one.

 What's a reflected attribute?

A property and an HTML attribute kept in sync in both directions — set the attribute and the property updates, set the property and the attribute updates. It's what lets document.querySelector('rating-stars').value = 5 and <rating-stars value="5"> mean the same thing.

<copy-chip>

Feature-detects navigator.clipboard and copies its text attribute on click, or shows an inline status if the API isn't available.
